# Outcomes log

What actually happened when people used WINZ Advocate. This is the real signal — did
the person get what they needed? De-identified. Fed back into the eval loop
(`EVALS/RUN.md`, monthly outcome review).

Sources: the `Share what happened` GitHub issue, Bill's own supervised test sessions,
anything a user chooses to send.

**Never record identifying detail** — no names, client numbers, addresses, dates of
birth (the person's or a staff member's).

## Format

```
### YYYY-MM-DD — [short situation]
- Asked for: …
- Tool advised: …
- What the person did: …
- Outcome: granted / declined / declined-then-overturned / still waiting / gave up
- $ recovered (rough, optional): …
- What the tool got right: …
- What the tool missed or got wrong: …  → IMPROVEMENTS.md?
```

## What we're watching for

- **Entitlements most often missed** by the tool → raise their priority in the prompt
  and `commonly-missed.md`
- **Decisions most often overturned** on Review → the tool should push these harder,
  earlier
- **Where drafts weren't good enough** → tighten the template
- **Where the person got stuck or gave up** → a usability or momentum problem
- **Myths that keep coming up** → add to the myths table
