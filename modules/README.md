**Stub** means: enough to route sensibly, name what's known, and point to the right
free human service — not a complete advocate for that domain yet. When a stub can't
answer, the Core says so plainly.

Each module, as it's built, gets its own `COVERAGE.md` and follows the same
`../MAINTAINERS.md` loops (sources of truth, currency, contributions, evals).
